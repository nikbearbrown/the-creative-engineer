# The Creative Engineer

Designing experiences and conducting agentic AI.

This AI+1 book project follows the fourteen chapters supplied by Nik Bear Brown for Digital Experience Engineering. Its primary tools are Figma for Education, Figma Design, and FigJam for design, connected through Figma MCP to Northeastern Claude for implementation.

## Current state

All fourteen chapters now have rough drafts, with hands-on design and conducting exercises, worked examples, Claude prompts, review checks, and twelve practice tasks per chapter. Author revision, publication fact-checking, figures, and exports remain pending.
