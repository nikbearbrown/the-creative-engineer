## Proposed hands-on adaptation

For the assistant, compare finding a resource with receiving an answer automatically. Create an evidence ledger with source, date, observed behavior, inference, and uncertainty. Add two competing briefs in FigJam. Ask Claude to identify who benefits and who bears a failure cost. Select one brief and state which observation would reverse the decision. Product and portfolio projects use the same structure; neither requires a chatbot.

### Candidate conducting prompt

> Challenge this brief using only the attached ledger. Give three genuinely different problem framings. For each, name affected people, exclusions, evidence gaps, and one falsifying observation. Do not fabricate user testimony.

## Evidence and failure checks

Reject a measurable target with no affected party. Flag duplicate observations. A completed ledger schema does not prove an interpretation correct. Simulated personas may help rehearse questions but cannot count as interviews.
