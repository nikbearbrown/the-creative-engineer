### W04 — Set up the remote server

Figma. [Set up the remote server](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/). Primary official documentation. Accessed 2026-09-29.

Claude Code setup offers a recommended Figma plugin and manual HTTP configuration. Manual command: `claude mcp add --transport http figma https://mcp.figma.com/mcp`. Authenticate and inspect connection using `/mcp`. The documented plugin command is `claude plugin install figma@claude-plugins-official`. These commands were checked against documentation, not executed in NEU's environment.
